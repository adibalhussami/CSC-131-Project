# How to Run Locally

Must be installed: Java and Maven.

Open 'waste-dashboard -Kyle' directory in terminal and enter:
1. `mvn clean package`
2. `java -jar target/waste-dashboard-0.0.1-SNAPSHOT.jar`

In your web browser, go to URL: "http://localhost:8080/"
The admin username is "admin", and the password is "wastedashboard".
